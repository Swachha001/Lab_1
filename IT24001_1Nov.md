### 2.3 Source code: `PrimeJdbc.java`

```java
import java.sql.*;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class PrimeJdbc {

    // ---- Database configuration (change to match your setup) ----
    private static final String URL  = "jdbc:mysql://localhost:3306/lab_db?useSSL=false&serverTimezone=UTC";
    private static final String USER = "root";
    private static final String PASS = "your_password";
    private static final String TABLE = "swachha_swapnil_prime";

    /**
     * Returns the n-th prime number (1st prime = 2).
     * Uses trial division against the primes found so far.
     */
    static long nthPrime(int n) {
        List<Long> primes = new ArrayList<>();
        long candidate = 2;
        while (primes.size() < n) {
            boolean isPrime = true;
            for (long p : primes) {
                if (p * p > candidate) break;      // no need to test beyond sqrt
                if (candidate % p == 0) {          // divisible -> not prime
                    isPrime = false;
                    break;
                }
            }
            if (isPrime) primes.add(candidate);
            candidate++;
        }
        return primes.get(n - 1);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter n (to find the n-th prime): ");
        int n = sc.nextInt();

        if (n < 1) {
            System.out.println("n must be a positive integer.");
            return;
        }

        long prime = nthPrime(n);
        System.out.println("The " + n + "-th prime number is: " + prime);

        // try-with-resources closes the connection automatically
        try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {
            System.out.println("JDBC connection established successfully.");

            // 1) Create the table if it does not exist yet
            String createSql = "CREATE TABLE IF NOT EXISTS " + TABLE + " ("
                    + "id INT AUTO_INCREMENT PRIMARY KEY, "
                    + "n INT NOT NULL, "
                    + "prime_value BIGINT NOT NULL, "
                    + "created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP)";
            try (Statement st = conn.createStatement()) {
                st.execute(createSql);
            }

            // 2) Insert using a PreparedStatement (prevents SQL injection)
            String insertSql = "INSERT INTO " + TABLE + " (n, prime_value) VALUES (?, ?)";
            try (PreparedStatement ps = conn.prepareStatement(insertSql)) {
                ps.setInt(1, n);
                ps.setLong(2, prime);
                int rows = ps.executeUpdate();
                System.out.println("Rows inserted: " + rows);
            }

            // 3) Retrieve and display the stored records
            String selectSql = "SELECT id, n, prime_value, created_at FROM " + TABLE + " ORDER BY id";
            try (Statement st = conn.createStatement();
                 ResultSet rs = st.executeQuery(selectSql)) {
                System.out.println("\nStored records:");
                System.out.printf("%-5s %-8s %-12s %s%n", "ID", "n", "Prime", "Created At");
                while (rs.next()) {
                    System.out.printf("%-5d %-8d %-12d %s%n",
                            rs.getInt("id"),
                            rs.getInt("n"),
                            rs.getLong("prime_value"),
                            rs.getTimestamp("created_at"));
                }
            }

        } catch (SQLException e) {
            System.err.println("Database error: " + e.getMessage());
            e.printStackTrace();
        }
    }
}
```

Apache Tomcat 10.1 was downloaded, extracted, and added to IntelliJ IDEA Ultimate as an application server. Tomcat 10.x uses the `jakarta.*` namespace, so the servlet code in Task 4 uses `jakarta.servlet`.

### Steps
1. Downloaded the **Core → zip/tar.gz** package from https://tomcat.apache.org/download-10.cgi
2. Extracted it to a folder, for example `C:\apache-tomcat-10.1.x` (Windows) or `~/apache-tomcat-10.1.x` (Linux/macOS).
3. Made sure `JAVA_HOME` points to the JDK:
   ```bash
   # Linux / macOS
   export JAVA_HOME=/path/to/jdk-17
   # Windows (cmd)
   setx JAVA_HOME "C:\Program Files\Java\jdk-17"
   ```
4. Added Tomcat to IntelliJ: **Run → Edit Configurations → + → Tomcat Server → Local**.
5. Next to *Application server*, clicked **Configure…**, then selected the Tomcat home folder.
6. In the **Server** tab: URL `http://localhost:8080/`, HTTP port `8080`, JRE set to JDK 17.
7. In the **Deployment** tab: clicked **+ → Artifact** and selected `PrimeServlet:war exploded`, with *Application context* `/PrimeServlet`.
8. Clicked **Run**, and Tomcat started.
9. Verified at `http://localhost:8080/`. The Tomcat home page (or the deployed application) loads.

### Alternative: start Tomcat manually from the command line
```bash

cd apache-tomcat-10.1.x/bin
./startup.sh

# Windows

```

### 4.4 Servlet: `PrimeServlet.java`

```java
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

import java.io.IOException;
import java.io.PrintWriter;

/**
 * Checks whether a number given by the user is prime.
 * Mapped to /prime in WEB-INF/web.xml
 * Example: http://localhost:8080/PrimeServlet/prime?number=17
 */
public class PrimeServlet extends HttpServlet {

    /** Returns true if n is a prime number. */
    private boolean isPrime(long n) {
        if (n < 2) return false;
        if (n == 2) return true;
        if (n % 2 == 0) return false;
        for (long i = 3; i * i <= n; i += 2) {   // test odd divisors up to sqrt(n)
            if (n % i == 0) return false;
        }
        return true;
    }

    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType("text/html;charset=UTF-8");
        String input = request.getParameter("number");

        String message;
        String color;

        if (input == null || input.trim().isEmpty()) {
            message = "Please enter a number.";
            color = "#555";
        } else {
            try {
                long number = Long.parseLong(input.trim());
                if (isPrime(number)) {
                    message = number + " is a PRIME number.";
                    color = "green";
                } else {
                    message = number + " is NOT a prime number.";
                    color = "red";
                }
            } catch (NumberFormatException e) {
                message = "Invalid input. Please enter a whole number.";
                color = "orange";
            }
        }

        try (PrintWriter out = response.getWriter()) {
            out.println("<!DOCTYPE html>");
            out.println("<html><head><meta charset='UTF-8'><title>Prime Checker</title></head>");
            out.println("<body style='font-family:Arial; text-align:center; margin-top:60px;'>");
            out.println("<h1>Prime Number Checker</h1>");
            out.println("<form action='prime' method='get'>");
            out.println("  <input type='text' name='number' placeholder='Enter an integer'>");
            out.println("  <button type='submit'>Check</button>");
            out.println("</form>");
            out.println("<h2 style='color:" + color + ";'>" + message + "</h2>");
            out.println("</body></html>");
        }
    }
}
```

### 4.5 Servlet mapping: `WEB-INF/web.xml`
